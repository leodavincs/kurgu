# Lower-third pack (3 styles)

Three name-plate styles on one 12 second timeline: minimal line, white card, bold block. Copy the style you like into your own project and change start, end and text.

- Size: 1920x1080 (16:9), 30 fps, 12 s
- Fonts: bundled OFL fonts only. Media: generated by this repo's code (`scripts/examples/`), no third-party material.
- Media lives in `templates/_media/` (shared) and this folder's `media/`.

## Start from it

```
python3 scripts/examples/new_project.py lower-thirds ~/videos/my-video
python3 server.py ~/videos/my-video
```

`new_project.py` copies this folder and every shared clip / sound it needs into `my-video/media/`, so the project is self-contained.
An agent does the same: copy the folder, then edit `project.json` (patch, do not rewrite).

## What to replace

- Style A: layers `ltA_*`. Style B: `ltB_*`. Style C: `ltC_*`. Each style is independent; keep one, delete the others.
- Text layers `*_name` and `*_role`: name and role. Text width is measured for left alignment, so after a long name nudge `x` of that style's text layers.
- `start` / `end` of every layer of a style together (or use `edit_project` to shift them by an offset).
- `bg`: your footage (the placeholder is a dimmed bokeh loop).

Colours: A accent `#7ee7ff`, B card white with a violet dot `#7c5cff`, C block `#7ee7ff` with a dark strip.

## Layers

- **Style A**: `ltA_role`, `ltA_name`, `ltA_bar`
- **Style B**: `ltB_role`, `ltB_name`, `ltB_dot`, `ltB_card`
- **Style C**: `ltC_role`, `ltC_name`, `ltC_strip`, `ltC_block`
- **Picture**: `bg`
- **SFX**: `sfx_a`, `sfx_b`, `sfx_c`

## Suggested agent prompt

> Take style B from templates/lower-thirds and put it on my clip media/interview.mp4 at 8 s for 4 seconds with the name "Dr. Mira Example" and role "Marine biologist". Also add style A at 31 s for the second guest, "Jon Sample", "Host".
