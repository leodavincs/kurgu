@@ description
Render one frame at time t (seconds) and return it as an image so you can look at it. Check first frame, titles, the end, after every visual change, and after moving or placing something for a note, before notes_done: compare the edges with the content around it. draft=true (default) is fast, half resolution (image px x2 = project px). CLI twin: `kurgu frame <dir> <seconds>`.
