@@ description
Blocks (up to timeout, default 120 s, max 3500) until the user clicks the send button in the editor, then returns the notes of that send (notes carry layer `bounds` + `anchor`: position from those, align edges with neighbours; a layer with `source` was made by code: fix the named source file, align with the mark's measured `elements_under`, then `rerender` the unit and look). Loop: notes_wait -> fix -> render_frame and look -> notes_done -> notes_wait. A saved cursor (.kurgu/inbox.cursor) remembers what you already got, so a send made while you were fixing is returned by the next call. On timeout just call again; in Codex keep the timeout at or below 120 and call again (3000 when the user is watching live).
